# Autonomous Code Review — Module 4

Module 4 consumes findings from static analysis (Member 1), AI analysis (Member 2), and risk analysis (Member 3). The sample JSON inputs use the shared finding ID `F001` to represent the same issue across all three modules.

## Current scope

This scaffold covers project structure and the common JSON input format. The sample inputs are illustrative; replace them with the teammates' actual outputs before implementing and integrating the verifier. Verification engine, API, dashboard, and final report generation are intentionally not implemented yet.

## Python

The workspace Python installation is 3.14.2, which satisfies the 3.10+ requirement. See `requirements.txt` for the backend dependencies.
